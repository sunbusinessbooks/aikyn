# AIkyn Core

AIkyn Core — модульная AI-платформа для локальных и серверных AI-систем.

## Возможности
- LLM inference
- Vision / multimodal analysis
- Production RAG
- OCR pipelines
- Agent workflows
- Monitoring and evaluation

## Архитектура
User → API → Orchestrator → (LLM / Vision / RAG / OCR / Agents)

## Базовый стек
- FastAPI
- vLLM
- Qdrant
- Redis
- PostgreSQL
- PaddleOCR
- Prometheus
- Grafana
- Nginx
